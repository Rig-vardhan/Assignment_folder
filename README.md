# Git Assignment

## Summary

This repository contains a complete hands-on implementation of core and advanced Git operations. The purpose of this assignment is to develop a strong understanding of version control concepts and real-world Git workflows.

The assignment starts with initializing a local repository, creating files, and performing basic operations like staging, unstaging, and committing changes. It also demonstrates the use of different commands such as `git restore` and `git reset` for managing the staging area.

Remote repository operations are covered by connecting the local repository to GitHub, pushing commits, and pulling updates made through the web interface. The workflow also includes selectively staging files and managing changes efficiently.

Branching and collaboration are key parts of this assignment. It involves creating branches, working on separate features, pushing changes, and creating pull requests. Merging branches and resolving merge conflicts manually are also demonstrated.

Advanced Git concepts such as soft reset, hard reset, partial commits using `git add -p`, and comparing branches using `git diff` are included to enhance practical knowledge.

The assignment also covers branch management (creation, merging, deletion), working with forked repositories, and contributing through pull requests.

Finally, complex scenarios involving staged and unstaged changes, stashing, applying stashes, conflict resolution, file removal, and reverting commits are performed to simulate real development challenges.

## Outcome

By completing this assignment, a solid understanding of Git workflows, collaboration techniques, and version control best practices is achieved.
